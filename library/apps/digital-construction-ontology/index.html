How to read this example · corrections · provenance
Read the arrow before the picture
An ontology supplies names and constraints for concepts and relationships. A case model chooses which real or illustrative things to describe with those terms. A source supporting a fact does not automatically validate its ontology mapping.
An import makes another ontology’s definitions available. A role is something an agent bears. An appointment records a relationship between an appointing and an appointed party. The diagram layout is only an aid to reading.
To share the interactive example, use this page’s link. Discussion tools such as Loomio may remove scripts from pasted content; use a link, or an iframe only where the host permits it.
