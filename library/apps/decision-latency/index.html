A small knowledge-graph project

Eight activities build a tag-concurrence visualiser. Some overlap; five associated decisions take different amounts of time. Select a task or decision to trace those supplied associations across both charts.

How to use · what the picture can tell you

Use a task bar, a decision bar, or the selection list below. Keyboard users can Tab to a bar and press Enter or Space. Related tasks gain an outline; the selected decision is marked in words as well as colour. Clear the selection to see the whole example.

The timeline shows task dates; the bars on the right show elapsed days from a decision being raised to closure. The sample contains no decision dates, dependency network or measured waiting time. A gap between tasks therefore cannot be attributed to a decision, and these charts do not calculate a critical path or prove that an approval caused delay.

Task intervals run from the start of the start date to the start of the finish date (finish exclusive), using UTC calendar days. Weekends and working calendars are not modelled. Decision-to-task links are illustrative associations, not tested gating rules.
