Original live-field/integration architecture is retained as an explicitly unimplemented hypothesis, separate from the working lexical comparison.

Corrections: local CSV parser and serializer handle quotes, commas and embedded newlines; the original demo's malformed CSV is fixed. Imports validate IDs/active flags/numbers/outcome references and target shares before changing state. Partial missing priors are rejected, all missing priors become equal shares, zero effort remains zero, and unmatched work stays unallocated. Unmatched entropy is N/A and excluded from entropy ranking/histograms. Boundary ties are retained; normalised match weights are not calibrated probabilities. Move impacts use portfolio effort units and an explicit transfer; suggestions are independent alternatives. Targets edit directly and immediately recompute; Reset restores loaded shares. Outcome updates respect declared realised intent, otherwise use top lexical match, and can run once per reset. No KL divergence, field solver, minimal-set optimiser, investment validation or RL guarantee is claimed.

Rendering uses escaped imported text and labelled controls. Export formula-like strings are protected for spreadsheet opening; ordinary numeric strings remain numeric. Existing export columns remain, with added move-transfer/intent-ID columns. The legacy `p_top`/`probability` columns contain allocation weights. Local canvas rendering replaces Chart.js; a chart-value disclosure gives accessible numerical results. No external runtime dependencies, local storage or automatic saving. Inputs remain in the user's CSV files; nothing is uploaded.
