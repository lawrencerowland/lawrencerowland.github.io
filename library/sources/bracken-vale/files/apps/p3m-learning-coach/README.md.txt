# P3M learning coach — 4.2

Four invented, source-linked exercises cover bounded scope, access evidence, sponsor decisions and a transfer case involving repeated monitoring observations. New learners begin with foundations; experienced learners begin with the unfamiliar transfer problem. Role and project context explain or reorder the route. **Revise my route** preserves attempts and chooses unfinished work.

Each **Submit case evidence** attempt contains two substantive case judgements and a written rationale. A case passes only when both judgements match the declared reference and the rationale has at least 30 characters and the required source ID. These rules are visible: rationale length/citation is not semantic grading. Incorrect answers produce case-specific feedback and a retry status. Visiting lessons and requesting context do not earn progress. The latest attempt determines each displayed case state.

The recorded coaching paragraph was genuinely authored during the 2026-10-03 build against the original access case. It is explicitly not generated from the learner's answer. All profile choices and attempts are inspectable, explicitly saved by the common shell and clearable with **Clear all exercise progress**. No other applications are observed.

Compared with a reading checklist, the route requires changed answers and cited reasoning. Passing synthetic checks is not professional certification. Full conversational AI coaching, independently vetted feedback and held-out learning-benefit evaluation remain open. Tests cover experience differences, click-free progress, false agreement feedback, required evidence, reset and malformed inputs/reopen.
