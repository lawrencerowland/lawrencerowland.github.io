# Micro-project workspace — 2.3

A local facilitated workspace for three invented office tasks: renewal register checking, station-workshop preparation and monitoring-data review. A charter identifies problem, output, owner and acceptance check. Recorded proposals were genuinely authored by the implementation assistant on 2026-10-03 against each fixed invented brief. They are not regenerated after charter changes. User proposals are separately labelled. Only **Accept proposal as task** creates a parent-project/version-linked task; completion requires a review note.

Walkthrough: edit a charter and **Save charter version**; accept a proposal; inspect the task board. Change the local owner, then use the built-in incoming sample with **Inspect incoming branch**. Three-way comparison uses the known base, local and incoming values: unchanged-side edits merge into a proposal, while divergent edits require **Record conflict choice**. **Apply reviewed merge** needs every conflict resolved, a reviewer and a rationale. Current charter remains unchanged until that explicit application. Snapshots and decision history are retained. Wrong project or fabricated base snapshot is rejected.

Each branch and exported whole-workspace bundle retains parent project and charter versions. Compared with whole-document replacement, the merge makes field conflicts visible. This is file exchange, not simultaneous collaboration, authenticated attribution or a trusted audit trail. Full functional completion would require actual AI co-creation plus an authenticated shared workspace with simultaneous-user, access and rollback tests. No generated code executes. Tests cover three-way conflict, remote-only change, atomic failures, human task acceptance, completion evidence, parent/version retention and escaping/reopen.

Team-role comments are explicitly local attributions, not messages sent to real people. Two invented initial comments expose sponsor/reviewer concerns; **Add role comment** stores a role, text and exact charter version without accepting a proposal. The full review bundle retains this discussion alongside decisions.
