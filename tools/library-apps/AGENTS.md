# Maintained Library apps

These existing React examples were deliberately preserved during retirement of React_proj-apps. This is a scoped exception to the root site's preference for unbundled examples: keep the maintainable source and pinned build, publish static output into library/apps, and do not re-create a separate React app collection.

Run `npm ci`, `npm test`, and `npm run build` here using Node 24. Commit regenerated library/apps output with source changes. Metadata and reading frames come from _data/library_apps.json and _data/library_themes.json. Preserve useful interaction, explanations and model data. Do not mistake UI test passes for empirical validation of the model. Use the feature inventory in MIGRATION.md when changing an example.
