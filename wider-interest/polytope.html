Projection mode

Drag to orbit; scroll or pinch to zoom; right-drag or two-finger drag to pan. Keyboard: focus the view, use arrows to orbit, Shift + arrows to pan, + / − to zoom, Home to reset.

If you see a blank screen: some browsers block ES-module imports for local files. Fix: run a tiny local server in this folder (e.g. python -m http.server 8000) and open http://localhost:8000/.
